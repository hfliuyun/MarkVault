1. 音频流转全链路回顾

在开始枯燥的参数解析之前，我们先在脑海中建立音频数据流转的宏观链路。从你对着麦克风说话，到观众在耳机里听到声音，音频数据经历了如下蜕变：

text
麦克风采集
  → 得到 PCM 原始音频（体积巨大）
  → 送入编码器进行 AAC 压缩（体积骤减）
  → 封装为 ADTS 裸流，或装进 MP4 / FLV 等容器
  → 网络传输 → 解封装 → AAC 解码 → 声卡播放

在这个链路中，PCM 是声音最原始的物理切片，而 AAC 则是为了网络传输而发明的“听觉欺骗”压缩魔法。

2. 探秘声音的数字躯壳：PCM

PCM（Pulse Code Modulation，脉冲编码调制）是一种将连续的模拟声波，转换为计算机能够理解的离散数字样本的方法。

2.1 采样定理与核心参数

参数含义常见取值
Sample Rate一秒钟内对声波进行多少次切片记录44100 Hz、48000 Hz
Bit Depth每次切片用多少 bit 表示振幅16-bit、24-bit
Channels同时记录多少条独立的声音轨迹1、2
为什么 CD 的采样率是 44.1 kHz？

根据奈奎斯特-香农采样定理，采样率必须大于等于信号最高频率的 2 倍。人耳上限约 20 kHz，所以至少 40 kHz。

一秒钟 PCM 数据的体积可以直接算出来：

Size = SampleRate × BitDepth × Channels ÷ 8
python
def pcm_bytes_per_second(rate, bits, channels):
    # 44100 × 16 × 2 ÷ 8 = 176400 B/s
    return rate * bits * channels // 8

位深越高，量化噪声越小，记录的声音细节越丰富。

注意

WAV 只是容器，里面装的通常就是未压缩的 PCM 数据。

3. AAC 编码

AAC 利用人耳的听觉掩蔽效应，丢掉听不见的部分，再用 MDCT 变换和熵编码把体积压到原来的十分之一左右。
